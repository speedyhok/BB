Engine Pipeline

IMPORT & COLLISION WORKFLOW

Step-by-step instructions for importing the 3D city into Unreal Engine 5, Unity, and Godot 4.

UNREAL ENGINE 5

Nanite & Lumen Ready

  1. Drag breaking_bad_albuquerque_master.glb into Content Browser.
  2. Set Import Uniform Scale = 1.0.
  3. Ensure One Convex Hull Per UCX is checked for auto-collision.
  4. Right-click meshes → Enable Nanite for high-performance mesh streaming.
UNITY (URP / HDRP)

Physics & Lighting

  1. Import folder into Assets/BreakingBad/.
  2. Set Model tab Convert Units = True.
  3. Use UCX_ child meshes as MeshCollider hulls.
  4. Add WheelCollider to vehicle wheel nodes for driving mechanics.
GODOT 4.X

Native GLTF 2.0

  1. Copy breaking_bad_albuquerque_master.glb into Godot project.
  2. Double-click to inspect nodes and material bindings.
  3. Instantiate as Node3D in your level scene.
  4. Lightweight 3.5MB footprint runs smoothly on Vulkan and Web export.
